About the Project

Rume is the biggest game I've been working on. It is a 3rd person horror shooter inspired by the Resident Evil game series. While the game is not complete yet it has taught alot when it comes to Unreal Engine.

What has been implemented so far:
Gun system: Multiple guns the player can use each with their own values tuned to be defferentiate between each of them.
AI: Simple zombie AI that roams around, chases the player after spoting them and attack when in range.
Item System: A inventory system that allows the player to pickup, use or drop items.
Interaction System: There are puzzles and other objects the player can interact with.

What I Learned

  • Blueprints: Most of my knowledge of Unreal Engine's Blueprint system comes from this project, while easier than C++ it is still very complex.
  • Procedural Environment: Unreal Engine has a system called Procedural Content Generation (PCG), I have used it to create forest and recently buildings. It requires alot setup but once functional it makes level creation much faster with more focus available on the look and layout instead of manually placing each peice and checking for gabs.
